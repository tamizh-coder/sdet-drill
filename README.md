# sdet-drill
SDET preparation repository with hands-on automation code, coding drills, and interview questions using Java, Python, and TypeScript. Covers Selenium, Playwright (MCP), and Appium with real-world framework examples, best practices, and problem-solving exercises for QA and SDET interview readiness.
